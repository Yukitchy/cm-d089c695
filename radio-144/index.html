Tour AI / #144 ゼロからの体験ツアーガイドラジオ 番組を聴く・読む

#144で話した、ツアーの仕事をやってくれるAI 6本

ラジオで「使い回せるものはリンクにして概要欄に載せます」と言ったやつです。秋葉原でアニメツアーをやっているユウキの現場で、実際に毎日動いているものだけを並べました。番組で話した6本だけです。

使い方は、コピーして貼るだけ

  1. 気になったツールの「AIへの頼み方」をコピーする
  2. Claude Code や ChatGPT など、手元のAIにそのまま貼る
  3. あとはAIの質問に答えていくと、あなたの環境用のものができます

まず「できあがるもの」を見てください。各ツールに実物の画面かリンクを付けました。自分の商売に置き換えられそうなものだけ、下の頼み方をコピーすれば十分です。
コピーは全文を。途中のURLも一緒に貼ってください。使うサービスを名指ししてある部分で、AIが勝手に別の作り方を選ぶのを防いでいます。
プログラミングの知識は要りません。ここに書いてあるのは全部「こういうことをしてほしい」という日本語の相談だけです。作る前に「今の自分の環境だと何が必要になる？」と聞くと、足りないものから教えてくれます。

01

毎朝ひとりでサイトを直すSEO担当

自分のツアーサイトが検索でどう見られているかを毎朝しらべて、直すところを提案して、そのまま直して公開までやってくれます。人間がやるのは提案に「GO」を押すことだけです。

できあがるもの

触れる見本 → 順位表を開く

直され続けている実物のサイト → animesenseijp.com

流れ

  • 入力 直したいことをためた台帳（ただの一覧表）
  • 処理 毎朝、台帳から1〜2件を選んで、実際にサイトを書き換える
  • 出力 検索の順位やクリック数の推移が見えるダッシュボード

人間の仕事

提案に「GO」を押す。効かなかった施策を台帳から外す。

使うサービス

  • Claude Code作業させるAI本体
  • Google Search Console検索の順位・クリック数の取得元。無料

AIへの頼み方

自分のサイトが検索でちゃんと見られているのか知りたいので、それが定期的に見られるダッシュボードを作ってほしいです。 そのうえで、毎朝あなたが自分で「今日直すならここ」を1〜2件選んで、私が「GO」と押したらサイトの修正から公開までやってくれる形にしてください。 直したいことは一覧表にためていく形にして、効かなかったものは私が外せるようにしてください。 【使うサービスはこれです。勝手に別のものに置き換えないでください】 ・Google Search Console（検索の順位とクリック数の取得元・無料） https://search.google.com/search-console/about ・作業はあなた（Claude Code / 手元のAI）が直接やる https://claude.com/claude-code まず、この構成で私の環境だと何が必要になるか教えてください。 できあがりの見本がここにあります。開いて構成を確認してから作ってください。 https://menu.animesenseijp.com/radio-144/demo/rank/
02

ダブルブッキングの見張り「かぶり番」

複数の予約サイトで同じツアーを売っていると、片方で予約が入ったときにもう片方を閉じ忘れて事故ります。それを見張って、ぶつかる時だけ知らせてくれます。

できあがるもの

出来上がるのはあなた専用のカレンダーとスマホ通知なので、公開できる実物がありません。届くのはこういう形です。

🚨 予定がぶつかっています 9/28(日) 10:00-14:00 で新しい予約が入りました。 同じ時間に別の予定が入っています。 どちらかを動かしてください。

触れる見本 → 見張りの画面を開く

ぶつからない日は何も届きません。ここが肝心で、毎回通知が来る作りにすると見なくなります。

流れ

  • 入力 予約サイトから届く予約・変更・取消のメール
  • 処理 5分おきにメールを読んで、予約用のカレンダーに書き込む
  • 出力 他の予定とぶつかる時だけスマホに通知。ぶつからない日は何も鳴らない

人間の仕事

鳴った時だけ判断する。何もない日は何もしない。

使うサービス

  • Google Apps ScriptGoogleのサーバー側で動くので、自分のパソコンが寝ていても動く。無料
  • 時間主導型トリガー5分おきに動かす設定。上のApps Scriptの機能
  • LINE Messaging API通知の送り先。無料枠あり

AIへの頼み方

複数の予約サイトで同じ商品を売っているので、ダブルブッキングが怖いです。 予約サイトから届く「予約・変更・取消」のメールを5分おきに読んで、専用のカレンダーに自動で書き込む仕組みを作ってください。 そのうえで、他の予定とぶつかる時だけスマホに通知してほしいです。ぶつからない日は何も通知しないでください。通知が多いと見なくなるので。 【使うサービスはこれです。勝手に別のものに置き換えないでください】 ・Google Apps Script（Google側で動くので自分のパソコンが寝ていても動く・無料） https://script.google.com/home ・時間主導型トリガーで5分おきに実行 https://developers.google.com/apps-script/guides/triggers/installable ・通知はLINE Messaging API https://developers.line.biz/ja/services/messaging-api/ ・予約メールの読み取りはGmail、書き込み先はGoogleカレンダー 自分のパソコンに常駐させる方式は、閉じている間に止まるので選ばないでください。 まず、この構成で私の環境だと何が必要になるか教えてください。 できあがりの見本がここにあります。開いて構成を確認してから作ってください。 https://menu.animesenseijp.com/radio-144/demo/kaburi/
03

ツアー写真の選別と、ゲストに渡すギャラリー

ツアー中に撮った何百枚の写真から、使える写真だけを機械的に選びます。ゲストに渡すページと、お礼のメッセージまで一緒に出てきます。写真は自分のパソコンの中だけで処理していて、外部のAIには送っていません。

できあがるもの

触れる見本 → 選別の画面を開く

流れ

  • 入力 その日に撮った写真と動画（家に帰って同期するだけ）
  • 処理 ブレ・明るさ・似た構図・写真としての良さで機械的に絞る
  • 出力 ゲスト用のギャラリーページ、お礼のメッセージ、投稿用の文章の案

人間の仕事

ギャラリーのリンクをゲストに送る。

使うサービス

  • Immich自宅のパソコンに置く写真管理。スマホから自動アップロード。無料・容量無制限（ハードディスク次第）
  • Claude Code選別とページ作成をさせるAI本体

AIへの頼み方

仕事で撮った写真が1日に何百枚もあって、選別に時間がかかっています。 その日の写真から、ブレているもの・暗すぎるもの・似た構図のものを機械的に外して、使えるものだけを残す仕組みを作ってください。 残った写真で、お客さんに渡せるギャラリーのページと、お礼のメッセージの下書きまで出してほしいです。 写真にはお客さんが写っているので、外部のサービスに送らず自分のパソコンの中だけで処理してください。 【使うサービスはこれです。勝手に別のものに置き換えないでください】 ・Immich（自宅のパソコンに置く写真管理。スマホから自動アップロード・無料） https://immich.app/ ・選別とページ作成はあなた（Claude Code / 手元のAI）がローカルでやる https://claude.com/claude-code GoogleフォトやiCloudなどのクラウドに上げる方式は選ばないでください。 まず、この構成で私の環境だと何が必要になるか教えてください。 できあがりの見本がここにあります。開いて構成を確認してから作ってください。 https://menu.animesenseijp.com/radio-144/demo/photos/
04

Instagramの投稿を組んで、確認だけ聞いてくる

選んだ写真から10枚組の投稿を作り、文章とハッシュタグまで用意して、「これで出していいですか」とスマホに聞いてきます。OKすると投稿されます。

できあがるもの

実際に投稿されたもの → この投稿 ／ アカウント

AIが最初に書いた文と、却下して直させた後の文の比べ → ビフォーアフター

触れる見本 → 組み立ての画面を開く

流れ

  • 入力 03で選ばれた、その日の写真
  • 処理 1枚目にまとめ画像、間に写真、最後にツアーの案内という並びで10枚に組む
  • 出力 文章の案が3つ。スマホに確認が届き、OKすると投稿される

人間の仕事

写真と文章の最終確認。ここで「この言い回しはクサい」と却下していくと、だんだん好みを覚えます。

使うサービス

  • Instagram Platform（公式API）自動投稿の正規ルート。プロアカウントが必要。非公式の自動化はアカウント停止の危険あり
  • LINE Messaging API投稿前の「これでOK？」を送る先
  • Claude Code組み立てと文章を書かせるAI本体

AIへの頼み方

お店（または仕事）の写真をInstagramに投稿するのが後回しになりがちです。 その日の写真から10枚組の投稿を自動で組んでください。1枚目はまとめ画像、最後の1〜2枚は自分の商品の案内を固定で入れたいです。 キャプションは3案出してください。そして投稿の前に必ずスマホに確認を送って、私がOKしたときだけ投稿するようにしてください。勝手に投稿はしないでください。 文章の好みは私が却下していくので、それを覚えていってください。 【使うサービスはこれです。勝手に別のものに置き換えないでください】 ・Instagram Platform（公式API。プロアカウントが必要） https://developers.facebook.com/docs/instagram-platform ・確認の通知はLINE Messaging API https://developers.line.biz/ja/services/messaging-api/ 非公式の自動化ツールやブラウザ操作での投稿は、アカウント停止の危険があるので選ばないでください。 まず、この構成で私の環境だと何が必要になるか教えてください。 できあがりの見本がここにあります。開いて構成を確認してから作ってください。 https://menu.animesenseijp.com/radio-144/demo/ig/
05

ゲストの希望から、行程案を2〜3つ作る

「東京で何か面白いことしたい」みたいなふわっとした問い合わせに、写真と地図つきの提案ページで返せるようになります。返信が早くて分かりやすいだけで、ゲストの反応が変わります。

できあがるもの

触れる見本 → 叩き台の画面を開く

流れ

  • 入力 ゲストの希望。アンケートの回答やメッセージの文面をそのまま渡すだけ
  • 処理 好みに合うルートを2〜3案。時間割・集合場所・回る順番まで組む
  • 出力 各案に写真が数枚と地図がついた提案ページ。昼食候補は営業日を確認した印つき

人間の仕事

叩き台を見て、ゲストに返事を書く。ゲストへの送信はAIにさせない。

使うサービス

  • Claude Code行程を考えてページを作るAI本体
  • Googleフォーム希望を受け取るアンケート。無料
  • Google Maps URLsルートの地図を埋め込む。この方式なら課金なし

AIへの頼み方

お客さんから「この日に案内してほしい」というふわっとした問い合わせが来ます。今は毎回、自分で候補を考えて文章で返していて時間がかかります。 お客さんの希望の文面を貼るだけで、行程の案を2〜3つ作ってくれる仕組みを作ってください。各案に、時間割・集合場所・回る順番を入れてください。 案ごとに写真を数枚と、回るルートの地図をつけた1ページにまとめてください。お客さんはA・B・Cから選ぶだけ、という形にしたいです。 お客さんへの送信はしないでください。最後は私が自分で送ります。 【使うサービスはこれです。勝手に別のものに置き換えないでください】 ・希望の受け取りはGoogleフォーム（無料） https://www.google.com/forms/about/ ・ルートの地図はGoogle Maps URLs（この方式なら課金なし） https://developers.google.com/maps/documentation/urls/get-started ・行程を考えてページを作るのはあなた（Claude Code / 手元のAI） https://claude.com/claude-code 地図APIの有料プランが必要になる方式は、先に私に確認してください。 まず、この構成で私の環境だと何が必要になるか教えてください。 できあがりの見本がここにあります。開いて構成を確認してから作ってください。 https://menu.animesenseijp.com/radio-144/demo/plan/
06

AIの使いすぎを週1で報告させる

AIに仕事をさせるほど料金や上限が気になります。週に1回、何にどれだけ使ったかと、無駄になっている部分を報告させています。番組で話した「暴走コスト防衛」の自分版です。

できあがるもの

自分のパソコンで開くだけのページなので公開していません。中身はこの形です。

今週つかった量: ◯◯（先週比 +◯%） 何に使ったか: 上から順に一覧 無駄の疑い 1. 毎朝動かしている◯◯が、実質使われていない 2. 同じ調べ物を毎回やり直している 3. 重い作業を上限の近い時間帯に寄せている やる番号を返信 → そのまま実装まで進む

触れる見本 → レポートの見本を開く

流れ

  • 入力 自分のAI利用の記録
  • 処理 週に1回、何にどれだけ使ったかを集計して、無駄を探す
  • 出力 使った量の一覧と、減らす案が番号つきで並んだレポート

人間の仕事

やる案の番号を返すだけ。そこから先は実行までやってくれる。

使うサービス

  • Claude Code集計対象であり、改善を実行する本体でもある

AIへの頼み方

AIに色々やらせるようになって、使用量と料金が読めなくなってきました。 週に1回、私が何にどれだけAIを使ったかを集計して、レポートにしてください。 そのレポートには「ここは無駄だったので、こうすれば減らせます」という改善案を、番号つきで並べてください。私が番号で返事をしたら、その改善をあなたが実行する形にしてください。 集計そのものにAIを使うと本末転倒なので、集計は普通のプログラムでやってください。 【前提】 ・対象は私が使っているAI（Claude Code など） https://claude.com/claude-code ・利用記録がどこに残っているかを、まずあなたが調べて私に教えてください ・レポートは1枚のHTMLで、ブラウザで開ければ十分です まず、この構成で私の環境だと何が必要になるか教えてください。 できあがりの見本がここにあります。開いて構成を確認してから作ってください。 https://menu.animesenseijp.com/radio-144/demo/token/

作ってみるときの、たった一つのコツ

番組でも話しましたが、最初の指示はふわっとしたままで大丈夫です。実際にこのSEO担当を作ったときの一言目は「自分が作ったサイトをちゃんと検索されてるのか知りたいから、定期的にこういうものが見れるダッシュボードを作ってほしい」だけでした。専門用語も設計図も要りません。AIの方が詳しいので、足りないところは向こうから聞いてきます。

うまくいかない時は、できあがったものを見ながら「ここはこうじゃなくて、こう」と言い直してください。何度かやりとりすると、だんだん自分の好みを覚えていきます。
